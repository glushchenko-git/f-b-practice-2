# RBAC Shop - Fullstack приложение с управлением доступом на основе ролей

## Описание проекта

Полноценное веб-приложение для управления товарами с системой ролей (RBAC). Реализована аутентификация с использованием JWT токенов, обновление токенов (refresh tokens) и разграничение прав доступа.

## Технологии

### Backend
- Node.js + Express
- JWT (jsonwebtoken)
- bcrypt (хеширование паролей)
- CORS

### Frontend
- React.js
- React Router v6
- Axios (с интерсепторами для работы с токенами)

## Установка и запуск

### 1. Клонирование репозитория
\`\`\`bash
git clone <your-repository-url>
cd fullstack-rbac-app
\`\`\`

### 2. Запуск Backend
\`\`\`bash
cd backend
npm install
npm run dev
\`\`\`
Сервер запустится на http://localhost:3000

### 3. Запуск Frontend
\`\`\`bash
cd frontend
npm install
npm run dev
\`\`\`
Приложение запустится на http://localhost:5173

## Система ролей и прав доступа

| Маршрут | Метод | Доступ | Описание |
|---------|-------|--------|----------|
| /api/auth/register | POST | Гость | Регистрация |
| /api/auth/login | POST | Гость | Вход |
| /api/auth/refresh | POST | Гость | Обновление токенов |
| /api/auth/me | GET | Пользователь | Текущий пользователь |
| /api/users | GET | Админ | Список пользователей |
| /api/users/:id | GET/PUT/DELETE | Админ | Управление пользователем |
| /api/products | GET | Пользователь | Список товаров |
| /api/products | POST | Продавец/Админ | Создание товара |
| /api/products/:id | GET | Пользователь | Детали товара |
| /api/products/:id | PUT | Продавец/Админ | Обновление товара |
| /api/products/:id | DELETE | Админ | Удаление товара |

##  Функциональность

### Для всех пользователей
- Регистрация и вход
- Просмотр списка товаров
- Просмотр детальной информации о товаре

### Для продавцов и администраторов
- Создание новых товаров
- Редактирование товаров

### Для администраторов
- Просмотр списка пользователей
- Редактирование информации о пользователях
- Блокировка пользователей
- Удаление любых товаров

##  Безопасность
- Пароли хешируются с помощью bcrypt (10 раундов)
- Access токен живет 15 минут
- Refresh токен живет 7 дней
- HttpOnly cookies для refresh токена (рекомендуется)
- Защита от XSS через Content Security Policy

##  Автоматическое обновление токенов

Фронтенд использует axios интерсепторы для:
1. Автоматической подстановки accessToken в заголовки
2. Перехвата ошибок 401 и автоматического обновления токенов
3. Повторной отправки оригинального запроса после обновления
